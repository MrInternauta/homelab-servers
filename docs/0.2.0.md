# Release 0.2.0 — Network-Wide Ad Blocking

Unreleased.

Adds **AdGuard Home**, a DNS server that blocks ads and trackers for every device that uses it —
the whole home LAN through the router, and every tailnet device anywhere through Tailscale. It is
the ninth stack; the lab is now **15 containers across 9 stacks**.

---

## Highlights

- **`adguard-home/`** — one container, `adguard/adguardhome` pinned to `v0.107.79` through
  `ADGUARD_VERSION`. DNS on port 53 (TCP + UDP), web UI on **3080** (`3080:3000`; the host's 3000
  is Obsidian).
- **State stays on the internal disk** (`./work`, `./conf`). DNS keeps answering while the NAS is
  down, and stack-guard leaves the stack running through a storage outage because it mounts
  nothing from `EXTERNAL_STORAGE`.
- **Every script knows about it.** `configure.sh`, `restart-all.sh` and `stack-guard.py` start it
  first, so DNS is up before the rest. `test-services.sh` probes its UI and checks that it
  resolves `example.com` and blocks `doubleclick.net`.

## Upgrade checklist

1. Pull, then `./configure.sh` — it creates `adguard-home/.env`.
2. 🐧 Free port 53 (one-time): `DNSStubListener=no` — see
   [SETUP.md § 5.9](../SETUP.md#59-adguard-home--port-3080-dns-on-53).
3. `docker compose -f adguard-home/docker-compose.yml up -d`, then run the wizard on
   `http://<host>:3080` — keep the admin port at **3000** and DNS at **53**.
4. Add blocklists and upstreams, including `[/ts.net/]100.100.100.100` for MagicDNS.
5. 🐧 `sudo ufw allow from <lan-subnet> to any port 53`.
6. Point the router's DHCP DNS at the host (no secondary) — on a stock Starlink router, set DNS
   per device instead (IPv4 **and** IPv6, see SETUP.md Step 8) — and set the host's Tailscale IP as a
   global nameserver with **Override local DNS**. On the server: `sudo tailscale set --accept-dns=false`.
7. `./test-services.sh` — the DNS section should show `example.com` resolving and
   `doubleclick.net` blocked.

**Rollback:** router DNS back to automatic, Tailscale override off,
`docker compose -f adguard-home/docker-compose.yml down`.
